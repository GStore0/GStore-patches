# AuroraStore-BYD-apps

Repository for building and publishing the `microg-patches.mpp` patch bundle using **Morphe**, targeting Android AOSP devices without built-in Google Mobile Services (GMS).

## Prebuilt APKs

Prebuilt APKs are no longer published as GitHub Releases. Instead, download the patch bundle and patch your own APKs using Morphe.

1. Download the latest [`microg-patches.mpp`](https://github.com/kangrio/AuroraStore-BYD-apps/releases/latest/download/microg-patches.mpp) patch bundle.
2. Obtain the original APK you want to patch.
3. Use the [Morphe CLI](https://github.com/MorpheApp/morphe-desktop) to apply the patch bundle to your APK.
4. Install the patched APK on your device.

This allows you to patch supported app versions yourself without relying on prebuilt APKs or waiting for a new release.
